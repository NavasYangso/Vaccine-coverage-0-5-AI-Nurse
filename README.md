# ระบบติดตามวัคซีนเด็ก 0–5 ปี

ไฟล์หลัก:

- `index.html` — หน้าเว็บ Standalone
- `Code.gs` — Google Apps Script Backend และฟังก์ชัน `setupSheets()` / `SetupSheet()`

## ติดตั้ง

1. สร้าง Google Sheets ใหม่
2. เปิด **Extensions → Apps Script** แล้ววางเนื้อหาจาก `Code.gs`
3. เลือกฟังก์ชัน `setupSheets` แล้วกด Run และอนุญาตสิทธิ์
4. ตรวจสอบตาราง `VACCINE_SCHEDULE` กับผู้รับผิดชอบงาน EPI ก่อนใช้จริง
5. เลือก **Deploy → New deployment → Web app**
6. ตั้ง **Execute as: Me** และกำหนดผู้เข้าถึงตามนโยบายของหน่วยงาน
7. นำ Web App URL ไปกรอกในหน้า `index.html`

บัญชีเริ่มต้นคือ `admin` / `admin` ระบบเก็บเฉพาะ password hash และ salt ในชีต `USERS` ไม่เก็บรหัสผ่านแบบข้อความตรง หลังเข้าสู่ระบบควรใช้เมนู `เปลี่ยนรหัส` และตั้งรหัสใหม่อย่างน้อย 6 ตัวอักษร

บทบาทที่เข้าสู่ระบบได้มี 2 ระดับ:

- `ADMIN` ผู้ดูแลระบบ จัดการบัญชีผู้ใช้และจัดการข้อมูลได้
- `EDITOR` เจ้าหน้าที่เพิ่ม แก้ไข นำเข้า และบันทึกข้อมูลได้

บัญชีที่ปิดใช้งานหรือบทบาทอื่นจะเข้าสู่ระบบไม่ได้ ผู้ดูแลเพิ่มบัญชีเจ้าหน้าที่จากเมนู `ผู้ใช้งาน` โดยระบบไม่ส่ง password hash หรือ salt ไปยังหน้าเว็บ

ผู้ใช้ใหม่สามารถกด `สมัครสมาชิกใหม่` จากหน้าล็อกอิน ระบบจะบันทึกบัญชีลงชีต `USERS` ด้วยสถานะ `PENDING` และ `ACTIVE = FALSE` จึงยังเข้าถึงข้อมูลไม่ได้ ผู้ดูแลต้องเปิดเมนู `ผู้ใช้งาน` ตรวจสอบคำขอ แล้วเลือก `อนุมัติและเปิดใช้งาน` ก่อน

เปิด `index.html` ด้วยเว็บเซิร์ฟเวอร์ เช่น VS Code Live Server หรือระบบ hosting ภายในหน่วยงาน ไม่แนะนำเปิดผ่าน `file://` เพราะบางเบราว์เซอร์จำกัดการเรียก API ข้ามโดเมน

## ชีตที่ระบบสร้าง

`SETTINGS`, `CHILDREN`, `VACCINE_SCHEDULE`, `VACCINE_RECORDS`, `FOLLOW_UP`, `COVERAGE_TARGETS`, `COVERAGE_DEFINITIONS`, `USERS`, `IMPORT_LOG` และ `AUDIT_LOG`

## รายงานความครอบคลุม

- หน้าเว็บมีกราฟแท่งและตารางสรุปรายวัคซีน แยกกลุ่มอายุ 1, 2, 3 และ 5 ปี
- `COVERAGE_TARGETS` เก็บจำนวนกลุ่มเป้าหมายสมมุติรายหมู่ 1–8 ตามไฟล์ Excel อ้างอิง
- `COVERAGE_DEFINITIONS` แมปชื่อรายงานใน Excel กับรหัสนัดวัคซีนในระบบ
- ร้อยละคำนวณจาก `จำนวนเด็กที่บันทึกว่าได้รับวัคซีน ÷ จำนวนกลุ่มเป้าหมาย × 100`
- วัคซีนรวม DTP-HB-Hib หนึ่งรายการสามารถนับเข้าส่วนประกอบ DTP, HBV และ Hib ตามนิยามรายงานได้

## การนำเข้าข้อมูล

หน้า `นำเข้าข้อมูล` รองรับ:

- ทะเบียนเด็ก โดยตรวจข้อมูลซ้ำจาก `CHILD_ID`, `CID` หรือ `HN`
- ประวัติการได้รับวัคซีน โดยอ้างอิง `CHILD_ID` และ `SCHEDULE_ID`
- จำนวนกลุ่มเป้าหมายสมมุติ แยก `AGE_GROUP` และ `VILLAGE_NO`

เจ้าหน้าที่สามารถดาวน์โหลดแม่แบบ CSV จากหน้าเว็บ เลือกไฟล์ CSV UTF-8 ที่บันทึกจาก Excel หรือคัดลอกช่วงเซลล์จาก Excel มาวาง ระบบจะแสดงตัวอย่างและตรวจข้อมูลก่อนยืนยัน โดยบันทึกผลการนำเข้าลง `IMPORT_LOG`

> ตารางวัคซีนในระบบเป็นข้อมูลตั้งต้นเพื่อการพัฒนาเท่านั้น ต้องตรวจสอบกับแนวทางวัคซีนล่าสุดของกรมควบคุมโรคก่อนนำไปใช้จริง
